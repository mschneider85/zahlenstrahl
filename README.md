# Zahlenstrahl-Generator

Erzeugt Zahlenstrahlen für Mathematik-Arbeitsblätter als SVG/PNG – mit frei wählbarem Bereich, Schrittweiten, Beschriftungs- und Strich-Ausnahmen sowie Kästchen zum Ausfüllen.

**Online:** https://mschneider85.github.io/zahlenstrahl/

Lokal: einfach `index.html` im Browser öffnen.
